# 浙江大学申请材料

本目录用于集中存放申请浙江大学电气工程相关导师的邮件材料与后续申请文本。

## 文件说明

- `给辛焕海老师-邮件个人陈述.md`：面向辛焕海老师的邮件正文与个人陈述，重点突出新能源与电力电子化电力系统稳定、PMSG 阻抗/导纳建模、系统强度和 AI 智能分析方向。
- `给丁一老师-邮件个人陈述.md`：面向丁一老师的邮件正文与个人陈述，重点突出电力市场、综合能源系统风险分析、需求侧管理、工程系统可靠性及相关软件开发/建模经历。
- `导师公开信息依据.md`：两位老师公开主页信息摘要与链接，便于后续继续更新材料。

## 本地参考资料

- `辛焕海老师论文/`：本地阅读参考资料文件夹，包含已阅读论文和 NE 电气公众号 PPT 截图。该文件夹用于写作依据，不随公开仓库提交。

## 使用建议

发送前建议根据实际附件情况补齐邮件正文中的附件列表，例如个人简历、成绩单、论文首页、获奖证明或科研成果证明等。
